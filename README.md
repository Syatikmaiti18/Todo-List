# Todo App 📝

A simple and responsive **Todo App** built using HTML, CSS, and JavaScript. This project helps users add and manage daily tasks with a due date.

## 🚀 Features

* Add new tasks with a due date
* Delete tasks
* Mark tasks as completed
* Clear all tasks
* Display total number of tasks
* Prevent empty task submissions
* Disable past dates in the calendar
* Responsive design for different screen sizes
* Simple and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – App functionality and DOM manipulation

## 📚 JavaScript Concepts Used

* Arrays and Objects
* Functions
* Loops
* If/Else conditions
* DOM Manipulation
* Event handling
* `push()` and `splice()`
* Date handling
